Which RoboTwin base tasks the 48 evaluation scenes build on

Every evaluation scene recombines objects, skills or success criteria from one or more native RoboTwin 2.0 tasks. This page lays out that source dependency: rows are the 48 formal evaluation scenes, columns are the 50 RoboTwin base tasks, and a filled cell means "this scene reuses something from that task".

Base tasks not used by any scene (16)

These are the current coverage gaps of the formal list. Most fall into bimanual coordination (pick_dual_bottles, place_dual_shoes), articulated-object manipulation (open_microwave, turn_switch) and dynamic motions (the two shake_bottle tasks), the three groups for which stable scripted experts are hardest to obtain.

The scene list is the 48 scenes frozen for formal evaluation (suite/scenes_v2.yaml / suite/seeds/, code tag formal-eval-v1 @ 39808b6; 3 of the original 51 were excluded for a scripted-expert yield below 30%). Dependencies come from the deps field of each scene in suite/table.py and, for the 8 hand-written scenes, from their original lineage in the v1 table suite/scenes.py; exported by suite/gen_depgraph.py. Success rates come from eval_result/formal_*, 100 episodes per scene with the same frozen seeds and instructions. "Source dependency" is a design notion, not code-level inheritance: every scene is implemented independently, but its objects, skills and criteria trace back to these native tasks. The registry labels the mixture family D7; it is shown as D6 here to match the paper. Generated 2026-09-21.
